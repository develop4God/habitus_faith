### 3. `lib/widgets/devotional_detail_content.dart` — Meditation section enhanced

**Issue:** Para Meditar section only displayed `punto.texto` (meditation text), missing the verse reference (cita).

**Fix:** Updated `_buildMeditationItem()` to display **both**:
1. **Verse reference (cita)** — displayed above, bold, smaller font (90% size)
2. **Meditation text (texto)** — displayed below, normal size

**Code change:**
```dart
// OLD: Only texto
Expanded(
  child: Text(punto.texto, ...)
)

// NEW: Both cita and texto
Expanded(
  child: Column(
    children: [
      Text(punto.cita, fontWeight: w600, fontSize: 90%),  // ← Verse ref
      SizedBox(height: 6),
      Text(punto.texto, fontSize: 100%),                  // ← Meditation
    ],
  )
)
```

**Example rendering:**
```
• John 3:16
  For God so loved the world that he gave his only son...
```
